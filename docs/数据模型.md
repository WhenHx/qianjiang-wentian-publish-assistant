# 数据模型

## 云端模拟模型

- `users`：业务用户；模拟环境只有 `demo-a` / `demo-b`。
- `devices`：设备，字段含 `user_id, name, status, token_hash, last_seen_at`。
- `binding_codes`：绑定码，含过期、尝试次数、单次下发凭证状态。
- `platform_accounts`：平台账号元数据，不含 Cookie/密码/完整登录状态。
- `materials`：素材元数据、哈希和本机受控存储路径。
- `tasks`：任务归属、平台、内容、内容版本、幂等键、状态、attempt、租约、提交意图、提交授权、结果。
- `task_events`：任务事件审计。
- `reports`：幂等结果回传。

## 本机模型

- `binding`：设备 ID 和 DPAPI 保护的设备凭证。
- `accounts`：随机 `account_key`、平台、昵称、随机浏览器配置目录、DPAPI 保护的可序列化登录状态、云端账号 ID。
- `local_tasks`：任务快照、下载路径、提交意图、report_key、最后错误，用于崩溃恢复。
- `settings`：本地接口令牌和少量配置。

## 隔离要求

- 云端以经过身份验证的 `user_id` 隔离，客户端请求体不提供租户字段。
- 本机账号目录只使用随机 ID，不使用昵称。
- 同一平台多个账号有不同浏览器配置目录。
- 服务端不接受任意本地路径。
