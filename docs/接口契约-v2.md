# 云端接口契约 v2（问天对接预留）

在 v1 基础上新增"已有视频发布"与"设备命令队列"。本轮仅模拟联调验证；真实问天接入时按本契约实现，数据库迁移依真实表结构另行编写。

## 1. 视频详情

`GET /api/v1/videos/{video_id}`（业务用户身份）

```json
{ "video": { "id": "video_...", "user_id": "user_...", "name": "演示视频", "version": "v1", "status": "ready", "material_id": "mat_...", "created_at": "..." } }
```

- `status`：`ready / processing / invalid`；只有 `ready` 可创建发布任务。
- 他人视频返回 404（不暴露存在性）。

## 2. 确认发布并创建任务

`POST /api/v1/publish-tasks`（业务用户身份）

```json
{
  "video_id": "video_...",
  "video_version": "v1",
  "platform": "douyin",
  "account_id": "acct_...",
  "device_id": "dev_...",
  "title": "标题",
  "description": "描述",
  "topics": ["话题"],
  "execution_mode": "desktop_assistant",
  "idempotency_key": "publish-..."
}
```

- 服务端校验：用户身份（从令牌解析，不信任请求体 user_id）、视频归属与 ready 状态、视频版本未漂移（不匹配 409 `video_version_mismatch`）、账号/设备归属与平台一致。
- 幂等：同 `idempotency_key` 返回原任务（200 + `idempotent_replay: true`）。
- `execution_mode` 预留区分旧 OpenClaw 流程与新桌面助手，避免同一任务被两条链路同时执行。
- 网页只传视频引用，不接受客户端提供的任意下载 URL。

## 3. 任务下发（设备侧，复用 v1 任务接口）

`POST /api/v1/tasks/claim` 返回的任务新增：

```json
{
  "execution_mode": "desktop_assistant",
  "video_id": "video_...",
  "video_version": "v1",
  "material": {
    "material_id": "mat_...",
    "download_url": "https://.../download?access_token=...",
    "download_url_expires_at": "...",
    "filename": "video.mp4",
    "content_type": "video/mp4",
    "size_bytes": 785183,
    "sha256": "hex 或 null"
  }
}
```

- `sha256` 不可用时必须显式为 `null`，不伪造。助手校验：大小、类型、有效视频编码（ftyp）、有哈希时严格比对。
- 任务不携带视频字节。

## 4. 下载授权刷新

`POST /api/v1/tasks/{task_id}/material-download`（设备身份 + attempt_id）

- 链接 401/403/410（过期/撤销类）时助手调用本接口刷新同一冻结视频版本的下载链接，重试一次。
- 任务已终态或取消返回 409；404 素材不存在、429 限流、5xx 临时故障分别处理，不一律当过期循环。
- 只刷新素材授权：不创建新任务、不变更账号与内容、不重发提交授权。
- 下载链接属敏感授权：日志不得记录完整签名参数。

## 5. 设备命令队列

网页侧对设备的结构化控制（白名单，禁止任意脚本/地址）：

`POST /api/v1/devices/{device_id}/commands`（业务用户）

```json
{ "type": "open_login", "payload": { "account_key": "localacct_..." }, "idempotency_key": "可选" }
```

- `type` 白名单：`open_login`（打开该账号本机登录窗口）、`recheck_account`（重新检查登录状态）。
- 命令含 ID、目标设备、有效期（10 分钟）、幂等约束（同类型同账号未执行完不重复创建）。

设备侧：

- `GET /api/v1/devices/commands`（设备身份，心跳时轮询）
- `POST /api/v1/commands/{command_id}/ack`：`{ "ok": true, "result": {...} }`

## 6. 正式/测试模式

- 正式：`submitMode: "auto"`，网页确认发布即授权，助手自动执行最终提交（身份、上传完成、字段读回、租约、内容版本、取消检查、提交授权全部门禁不变）。
- 测试：`submitMode: "hold_before_submit"`，停在提交前。界面横幅明示当前模式。
