# 安全说明

- 设备凭证由云端生成，本机使用 Windows DPAPI CurrentUser 保护。
- 平台登录状态保存在本机随机目录和 DPAPI 保护字段中，不上传云端。
- 日志会对 token、cookie、password、authorization 等字段脱敏。
- 本地控制接口只绑定 `127.0.0.1`，默认不对公网开放。
- 云端只下发结构化任务，不下发 Python/JavaScript/Shell 或任意浏览器脚本。
- 素材 URL 校验协议、DNS、内网地址、重定向、类型、大小和 SHA-256。
- 不提供验证码绕过、指纹伪装、代理轮换或风控规避。
- DPAPI 不能防御同一 Windows 用户下已经运行恶意进程的情况。
- 本测试包未签名；正式自动更新必须验证可信签名，当前未实现自动更新。

## 当前沙箱限制

本测试机沙箱身份无法使用 DPAPI CurrentUser。测试版在 `simulation + simulated` 模式下降级为显式的不安全本地存储并在日志中警告；真实平台 CDP 模式和生产模式禁止使用此降级。
