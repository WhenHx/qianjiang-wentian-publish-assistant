# 真实千匠问天服务端改动建议（未执行）

当前没有真实源码和数据库权限，以下是接入时应落地的最小改动清单，不代表已执行。

## 1. 任务执行路径分流

为发布任务增加字段：

- `execution_mode`: `manual | openclaw_legacy | desktop_assistant`
- 默认保持现有兼容值；新桌面助手任务使用 `desktop_assistant`。
- 抖音旧 OpenClaw 流程只处理 `openclaw_legacy`，桌面助手只领取 `desktop_assistant`。

## 2. 设备与绑定表

建议新增：

- `assistant_devices(id, user_id, name, status, credential_hash, created_at, last_seen_at, revoked_at)`
- `assistant_binding_codes(id, code_hash, poll_token_hash, status, device_id, attempts, expires_at, created_at, approved_at)`

设备凭证只保存哈希。绑定码短期、单次、限制尝试次数。

## 3. 平台账号元数据表

- `assistant_platform_accounts(id, user_id, device_id, platform, account_key, nickname, platform_identity, status, capabilities, last_check_at)`
- 不保存 Cookie、密码或完整登录状态。

## 4. 任务执行字段

在发布任务表或子表增加：

- `content_version`
- `idempotency_key`
- `attempt_id`
- `lease_expires_at`
- `submission_intent_at`
- `submit_authorized_at`
- `result_json`
- `error_json`
- `cancel_requested`

## 5. 幂等结果表

- `assistant_task_reports(id, task_id, attempt_id, report_key, result_json, created_at)`
- 唯一约束：`(task_id, attempt_id, report_key)`。

## 6. RLS 和权限

- 所有查询必须以认证用户 ID 为隔离边界。
- 客户端请求体的 `user_id` / `tenant_id` 不可信。
- 设备令牌只能访问归属用户的任务。
- 撤销设备立即失去领取、续租、授权和回传权限。

## 7. Edge Functions / API

按 `docs/接口契约-v1.md` 实现同名能力。若复用 `mv-task-claim` / `mv-task-ack`，必须新增客户设备鉴权，不能把内部 worker token 下发给桌面端。
