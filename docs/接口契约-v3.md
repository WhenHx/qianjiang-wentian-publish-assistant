# 云端接口契约 v3（平台互动接待：评论/私信/线索）

在 v1/v2 基础上新增"平台互动"与"留微线索"接口。本轮仅模拟联调验证；真实问天接入时按本契约实现，数据库迁移依真实表结构另行编写。

定位：问天是业务大脑（保存消息、知识库/AI 生成回复、判断意向）；助手是执行端（读取平台消息、发送回复、回传真实结果）。助手不本地生成客户回复。

## 1. 互动消息上行（设备身份）

`POST /api/v1/interactions`（Bearer 设备令牌）

```json
{
  "platform": "douyin",
  "account_key": "localacct_...",
  "kind": "dm",
  "peer": { "platform_uid": "对方平台标识或 null", "nickname": "对方网名" },
  "message": {
    "external_id": "平台消息标识或 null",
    "direction": "in",
    "content": "客户发来的原文",
    "sent_at": "2026-10-23T10:00:00Z"
  },
  "context": [{ "direction": "in|out", "content": "...", "sent_at": "..." }],
  "source": { "kind": "dm", "conversation_key": "单线程生物", "work_id": null },
  "idempotency_key": "int-..."
}
```

- `kind`：`dm`（私信）/ `comment`（评论）。
- 幂等：同 `idempotency_key` 返回原记录（200 + `idempotent_replay: true`），重复轮询不会重复建互动。
- 设备必须属于该账号的绑定用户；跨用户 404/403。

响应（201）——问天同步生成回复：

```json
{
  "interaction_id": "int_...",
  "reply": { "status": "ready", "text": "问天生成的回复内容" }
}
```

回复尚未生成时（异步模式）：

```json
{
  "interaction_id": "int_...",
  "reply": { "status": "pending" }
}
```

## 2. 回复拉取（异步兜底，设备身份）

`GET /api/v1/interactions/{interaction_id}`（Bearer 设备令牌）

```json
{ "interaction_id": "int_...", "reply": { "status": "ready|pending|none", "text": "..." } }
```

- `none`：问天决定不回复（如广告、无意义消息），助手收到后标记丢弃，不发送。

## 3. 发送结果回传（设备身份）

`POST /api/v1/interactions/{interaction_id}/result`（Bearer 设备令牌）

```json
{
  "outcome": "sent",
  "evidence": { "sent_text": "实际发送内容" },
  "error": null
}
```

- `outcome`：`sent / failed / waiting_user / discarded`。
- `waiting_user`：扫码、验证码、登录失效等需要人工的场景，**不能报成 failed**。
- 结果幂等：同 interaction 重复回传返回原结果；终态不可覆盖。

## 4. 留微线索上行（设备身份）

`POST /api/v1/leads`（Bearer 设备令牌）

```json
{
  "platform": "douyin",
  "account_key": "localacct_...",
  "peer": { "platform_uid": "...", "nickname": "客户网名" },
  "channel": "抖音",
  "contact": { "type": "wechat", "value": "微信号或手机号" },
  "raw_message": "客户原始消息全文",
  "source": {
    "kind": "dm",
    "conversation_key": "...",
    "interaction_id": "int_...",
    "work_id": null
  },
  "captured_at": "2026-10-23T10:00:00Z",
  "idempotency_key": "lead-..."
}
```

- `channel` 为获客渠道来源（抖音/视频号/小红书），贯穿到后续微信备注，不可被覆盖为"微信"。
- `contact.type`：`wechat / phone`。
- 幂等：同 `idempotency_key` 返回原线索（200 + `idempotent_replay: true`）。
- 助手只负责识别和组装，不加微信、不判意向；问天收到后自行下发加好友任务给微信模块。

## 5. 状态与安全约束（沿用 v1/v2）

- 所有设备接口校验设备归属；用户只能看到自己设备的数据。
- 互动记录与线索长期保存，不做定期删除。
- Cookie、设备凭据、浏览器登录态留在本机，接口不接收不上传。
- 登录失效时助手回传 `waiting_user` 并在本地界面显示"等待用户处理"，不绕过验证。
