# 使用说明（测试版）

## 环境

- Windows 11 x64。
- Node.js 24 或更高版本。
- Edge 或 Chrome（真实平台 CDP 模式需要）。
- 不需要安装 Python。

## 启动

```powershell
npm test
npm run dev
```

浏览器控制台：`http://127.0.0.1:8780/console`。

## 绑定设备

1. 在桌面助手首页输入设备名称，点击“申请绑定”。
2. 复制绑定 ID 和 6 位绑定码。
3. 在模拟控制台选择模拟用户，填写绑定 ID 和绑定码，点击“确认绑定”。
4. 回到桌面助手点击“轮询绑定结果”。

## 添加平台账号

1. 打开“平台账号”页。
2. 选择平台，输入本机备注昵称，点击“添加账号”。
3. 点击“打开登录窗口”，在独立浏览器窗口中完成登录。
4. 点击“检查登录状态”。
5. 模拟模式下不会访问真实平台，检查会返回模拟登录。

## 创建并执行任务

1. 在模拟控制台上传素材或使用受控测试素材。
2. 填写标题、描述、话题，选择平台、账号、设备。
3. 创建任务。
4. 桌面助手自动领取任务，默认停在“待最终提交”。
5. 只有明确点击“执行一次提交”才会进入提交阶段。
6. 提交后异常进入“结果待核实”，不会自动二次发布。

## 关闭与退出

关闭窗口默认最小化到托盘；托盘菜单选择“退出”才退出界面。助手核心是否继续运行取决于启动方式。电脑关机、休眠或助手离线时任务不能执行。
