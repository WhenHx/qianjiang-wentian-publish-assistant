# 故障排查

## 绑定一直 pending

- 确认模拟控制台选择的是正确业务用户。
- 确认绑定码未过期、未使用、未超过尝试次数。
- 检查助手核心日志：`runtime/logs/assistant-YYYY-MM-DD.jsonl`。

## 任务不被领取

- 桌面端必须显示已绑定。
- 设备在云端必须为 active。
- 任务目标设备必须是当前设备。
- 首版每台设备同一时刻只执行一个任务。

## 下载素材失败

- 检查短期授权 URL 是否过期。
- 检查素材 SHA-256 是否一致。
- 生产模式禁止本机/内网地址；仅本地模拟配置允许回环地址。

## 登录失效、验证码、扫码、实名验证

助手会停止自动点击和重试，并进入人工处理。请在独立浏览器窗口完成验证，然后点击“接管后继续”。不要关闭该窗口，除非准备取消本地接管。

## 提交后断网或助手崩溃

任务进入 `outcome_unknown`。不要重新创建相同内容任务，先到平台作品列表或结果页面核实，再在控制台人工确认。

## DPAPI 不可用

在正常 Windows 登录会话中应可用。若使用计划任务、服务、受限沙箱或未加载用户配置，DPAPI CurrentUser 可能失败。真实平台账号不得使用 `allowInsecureSecretStorage`。
